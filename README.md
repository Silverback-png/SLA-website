# Sober Living Angels — Official Website

A modern, fully responsive marketing website designed and developed by **Mana Software** for **Sober Living Angels**, a sober living home dedicated to providing a safe, supportive, and structured environment for individuals on their recovery journey.

## About the Project

Sober Living Angels needed a professional online presence that reflects the warmth, trust, and dignity of their mission. Mana Software delivered a clean, accessible, and performance-focused website that makes it easy for prospective residents and their families to learn about the home, its values, and how to get in touch.

### Key Features

- **Responsive design** — seamless experience across desktop, tablet, and mobile devices
- **Dark / light theme toggle** — respects system preferences and remembers user choice
- **Contact form** — integrated email notifications with spam protection (honeypot bot detection)
- **Scroll reveal animations** — subtle, polished interactions throughout the site
- **Accessible & lightweight** — built with semantic HTML, modern CSS, and vanilla JavaScript (no frameworks, no bloat)

## Tech Stack

- HTML5
- CSS3 (custom properties, responsive layout)
- Vanilla JavaScript
- EmailJS (contact form delivery)
